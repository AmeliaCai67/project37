# 問数 · Project 37
> 「万物は数なり。その法、久しく変わらず。」— **37**

![](assets/maxresdefault.jpg)

## 37 とは
**Project 37** は、あなたのために生まれた**個人用 AI データアナリスト**である。

このプロジェクトを作ったのは、AI に「渦中に囚われる苦しみ」からあなたを解き放ち、代わりに**「一歩外に立つ智」**を手渡したかったからだ。

かつて、膨大なデータから洞察を得るには、複雑な SQL、難解な分析理論、重く高価なエンタープライズ基盤と向き合わねばならなかった。あなたは雑然とした細部の只中に“身を置き”、その過程でデータが運んでくるものは、しばしば答えではなく苦痛だった。

**37 が現れたのは、この苦しみに終止符を打つためだ。**

- **技術の壁を砕く**：彼女は敷居を下げるために生まれた。複雑なデータ整備の流儀を知る必要はない。コードを一行書く必要もない。
- **極限まで軽やかに**：手順だらけのエンタープライズツールとは違う。37 は羽のように軽い。
- **「投げ入れる」だけでいい**：論文でも、Excel でも、Markdown のメモでも——すべて公文庫（アーカイヴ）へ放り込んでしまえばいい。

あとの導出、分析、検証——「数」に属する煩わしさと苦痛は、すべて 37 に委ねる。彼女はあのレトロな CRT の向こうでノイズを濾し取り、もっとも純粋な**「一歩外に立つ智」**だけを、あなたの机上へ届ける。

## 機能
- **真理探尋 (ReAct Agent)** — 単なる問答機ではない。複雑な課題を渡すと、彼女は `Thought → Action → Observation` の循環を開く。まず思考し、次に行動し、そして観察する。最終の答えが導かれるまで。

- **公文庫 (File Knowledge)** — Excel、PDF、CSV、文書を預けよ。彼女はそれらを「知の破片」とみなし、あなたの指示に従って精密に回収し、数字の奥に隠れた意味を掘り起こす。

- **数の直観 (Auto Analysis)** — 複雑な統計が必要か？ 彼女はその場で Python を「導出」し、安全な sandbox で走らせる。空虚な憶測ではなく、データの事実で語る。

- **燐光スクリーン (CRT Terminal)** — 思考のすべては、レトロな骨格を持つ CRT の上で起こる。燐光緑の単色の光、古いテレビの電源断ちのごとき演出。技術の鼓動に、重みのある物質感を。

- **安全守護 (Sandbox)** — 彼女の安全意識は容赦ない。すべてのコード実行は、AST 静的解析とサブプロセス隔離の二重の守りのもとにある。権限はあなたが握る。彼女があなたのプライバシーへ踏み越えることは、決してない。

## ダウンロード

1. [Releases](../../releases) からお使いの OS 向けビルドを入手する。
2. **Windows**：`Project37-Windows.zip` を展開し、`Project37.exe` をダブルクリック。
3. **macOS**：`Project37-Mac.zip` を展開し、`Project37.app` を Applications へドラッグ。右クリックから開く。
4. 初回起動時に DeepSeek API Key を入力すれば、すぐ使い始められる。

> 「開発元を検証できない」や SmartScreen の警告が出た場合は、「それでも実行」または「右クリック → 開く」を選ぶ。

## クイックスタート
### 1. 環境を目覚めさせる

Bash

```
cd backend && cp .env.example .env
# .env に API Key を記し、真理の門を開く
```

### 2. スクリーンを灯す（バックエンド + フロントエンド）

Bash

```
# バックエンド
pip3 install -r requirements.txt && python3 main.py

# フロントエンド
cd frontend && npm install && npm run dev
```
