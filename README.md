## 37 是什么
**Project 37** 是一个为你而生的**个人 AI 数据分析师**。

我开发这个项目的初衷，是为了让 AI 帮你摆脱“身处其中的痛苦”，**拥有“置身事外的智慧”**。

在过去，想要从海量数据中获取洞见，你通常需要面对复杂的 SQL 语句、晦涩的分析理论，或者是沉重昂贵的企业级平台。你被迫“身临其境”地去处理那些杂乱无章的细节，在这个过程中，数据带来的往往不是答案，而是痛苦。

**37 的出现，是为了终结这种痛苦。**

- **打破技术限制**：她专为降低门槛而生。你不需要懂得如何进行复杂的数据治理，也不需要写一行代码。
- **极致的轻量化**：不同于那些流程繁琐的 B 端产品，37 极其轻盈。
- **“扔”进去，就够了**：无论是论文、Excel 表格还是 Markdown 笔记，你只需要把它们**通通扔进文件夹**。

剩下的推导、分析、验证——那些属于“数字”的繁琐与痛苦，全部交给 37。她会在那台复古的 CRT 荧幕后，为你过滤掉噪音，只把最纯粹的、**“置身事外”的智慧**递到你的书桌上。

## 功能特性
- **真理探寻 (ReAct Agent)** — 她不是简单的问答机器。当你提出一个复杂任务，她会开启 `Thought → Action → Observation` 的循环。先观察，再思考，最后行动，直到推导出最终答案。
    
- **档案柜 (File Knowledge)** — 上传你的 Excel、PDF、CSV 或文档。她会将这些文件视为“知识的碎片”，根据你的指令精准检索，并挖掘出隐藏在数字背后的深意。
    
- **数学直觉 (Auto Analysis)** — 遇到复杂的统计需求？她会当场“推导”出 Python 代码，并在安全的沙箱中运行，用数据事实说话，而非空洞的猜测。
    
- **物理荧幕 (CRT Terminal)** — 所有的思考过程都发生在一个复古拟物化的 CRT 荧幕中。磷光绿的单色光芒、旧电视关机式的转场动画，让技术的跳动拥有了厚重的物理感。
    
- **安全法典 (Sandbox)** — 她拥有极其严格的安全意识。所有代码执行都通过 AST 静态分析与子进程隔离双重保护。她的权限由你掌控，绝不越权触碰你的隐私。

## 快速开始
### 1. 唤醒环境

Bash

```
cd backend && cp .env.example .env
# 在 .env 中填入你的 API Key，开启真理之门
```

### 2. 点亮荧幕 (后端 + 前端)

Bash

```
# 后端
pip3 install -r requirements.txt && python3 main.py

# 前端
cd frontend && npm install && npm run dev
```
